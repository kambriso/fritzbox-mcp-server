= Changelog

All notable changes to the FRITZ!Box MCP Server project will be documented in this file.

== Unreleased

=== Added
- `wifi_channel_environment` MCP tool switched to the FRITZ!Box REST API (`/api/v0/generic/wlan`, discovered by unpacking the official 7590 AX 08.25 firmware): triggers an on-demand neighbor scan and returns SSID, MAC, channel, band, channel width, and RSSI in dBm for each neighboring network
- Independent web-session (AVM-SID) authentication with PBKDF2 (FRITZ!OS 7.24+) and legacy MD5 challenge support
- Unit tests for login challenge-response, on-demand scan flow, and Lua-struct APEnv parsing with a fake FRITZ!Box
- OpenAPI contract for the FRITZ!Box REST API at `contracts/openapi.yaml` (extracted from FRITZ!Box 7590 AX firmware 08.25, `/usr/rest_api` Lua handlers); regenerated typed client lives in `restclient/client.gen.go` via `mise run generate-oapi-client`

== link:https://github.com/kambriso/fritzbox-mcp-server/releases/tag/v0.8.0[0.8.0] - 2026-02-10

=== Added
- Interactive setup command (--setup) with automatic SSDP discovery
- Support for detecting FritzBox Mesh Master during setup
- Secure credential handling with 0600 file permissions
- Parallelized TR-064 service discovery for near-instant startup
- Robust Go unit test suite for MCP logic and discovery
- New architecture diagram using Graphviz (.dot -> .svg)

=== Changed
- Migrated configuration logic to exclusively use global XDG directory
- Standardized license to Kambrium Source-Available License (KSAL-1.0)
- Improved USAGE.txt with setup-first documentation
- Removed deprecated --xml-dir flag and legacy caching logic
- Documentation clarified and all bold formatting removed

=== Fixed
- Nil pointer panic during server initialization in unconfigured state
- Corrected line endings in SSDP discovery responses for broader compatibility
