= Changelog

All notable changes to the FRITZ!Box MCP Server project will be documented in this file.

== link:https://github.com/kambriso/fritzbox-mcp-server/releases/tag/v0.7.0[0.7.0] - 2026-01-26

=== Added
- SLSA Level 3 provenance for GitHub releases
- SLSA Level 2 provenance for GitLab releases (cosign signatures)
- Cross-forge reproducible builds (GitHub and GitLab produce identical binaries)
- Make targets for SLSA verification
- GitLab release creation on tag push

- Version strings now follow semver (0.7.0 instead of v0.7.0)
- Separate TAG and VERSION variables in Makefile
