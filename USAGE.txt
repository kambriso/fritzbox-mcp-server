FRITZ!Box MCP Server - Usage Guide

MODES:
  1. MCP Server Mode (default)    - Interactive protocol server for AI agents
  2. Setup Mode                   - Interactive discovery and configuration
  3. CLI Execution Mode           - Execute single action and exit

=== MCP SERVER MODE (default) ===

When invoked without flags, runs as an MCP protocol server via stdin/stdout.

=== SETUP MODE ===

Usage:
  $ fritz-mcp --setup

Features:
  - Automaticaly discovers FRITZ!Box devices using SSDP
  - Identifies the Mesh Master (gateway)
  - Guides you through host, credential, and TLS setup
  - Saves configuration to .env with secure 0600 permissions

=== CLI EXECUTION MODE ===

Execute a single action from command line. Perfect for at/cron scheduling.

Usage:
  $ fritz-mcp --execute \
      --service <service-type> \
      --action <action-name> \
      [--args <json>] \
      [--quiet]

Required:
  --execute              Enable CLI mode
  --service <type>       Service type URN (e.g., urn:dslforum-org:service:DeviceInfo:1)
  --action <name>        Action name (e.g., GetInfo)

Optional:
  --args <json>          Arguments as JSON object (default: {})
  --quiet                Suppress logs, only print result

Examples:

  # Get device information
  $ fritz-mcp --execute \
      --service "urn:dslforum-org:service:DeviceInfo:1" \
      --action "GetInfo" \
      --quiet

  # Block device by IP
  $ fritz-mcp --execute \
      --service "urn:dslforum-org:service:X_AVM-DE_HostFilter:1" \
      --action "DisallowWANAccessByIP" \
      --args '{"NewIPv4Address":"192.168.178.35","NewDisallow":"1"}' \
      --quiet

  # Schedule with at (time-delayed blocking)
  $ echo 'fritz-mcp --execute \
      --service "urn:dslforum-org:service:X_AVM-DE_HostFilter:1" \
      --action "DisallowWANAccessByIP" \
      --args '"'"'{"NewIPv4Address":"192.168.178.35","NewDisallow":"1"}'"'"' \
      --quiet' | at now + 20 minutes

Discovery:
  Use MCP mode to discover available services and actions:
  - list_services     List all services
  - list_actions      List actions for a service
  - describe_action   Get action parameters

OTHER OPTIONS:
  --setup               Run interactive setup
  --version             Show version and exit
  --debug               Enable verbose debug logging

CONFIGURATION:
  Configuration is managed via the --setup command.
  Credentials are stored securely in your global config directory:
    ~/.config/fritzbox-mcp-server/.env (on Linux/macOS)
    %APPDATA%/fritzbox-mcp-server/.env (on Windows)

TIME-DELAYED ACTIONS (AI Agent Feature):
  When using with AI agents, you can request time-delayed actions:

  User: "Block device in 20 minutes"

  The AI agent will:
  1. Identify the device
  2. Create an at job: echo 'fritz-mcp --execute ...' | at now + 20 minutes
  3. Confirm with job ID for cancellation
